# First-motion hardware session scripts

These six documents are attended-session checklists. They contain the exact
CPU/emulator verification commands that were tested. They intentionally contain
no executable physical controller command because no installed collision
profile, measured plant profile, stage command package, or physical approval is
currently admitted.

The physical-command slot in each document remains a hard no-go until a separate
hash-bound package is produced by the existing first-motion staging and review
pipeline and Jack signs it for one attempt. Copying an emulator command into a
hardware transport is prohibited.
